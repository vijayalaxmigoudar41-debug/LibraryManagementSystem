# Library Management System

## Project Overview

Library Management System is a C++ console-based application developed using Object-Oriented Programming concepts. It demonstrates Inheritance, Polymorphism, Virtual Functions, Dynamic Memory Management, and File Handling.

The system manages library media items such as Books and Journals. Users can add items, display catalog details, checkout and return items, calculate overdue fines, and save catalog data into a file.

## Features

- Add Book
- Add Journal
- Display Library Catalog
- Checkout Items
- Return Items
- Fine Calculation for Overdue Items
- Save Catalog Data to File
- Load Catalog Data from File

## OOP Concepts Used

### Inheritance
MediaItem is the base class and Book, Journal are derived classes.

### Polymorphism
Virtual functions are used to display different media item details.

### Dynamic Memory Management
Pointers are used to manage objects dynamically.

## Technologies Used

- C++
- Object-Oriented Programming
- File Handling
- STL Vector
